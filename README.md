# Портфолио веб-разработчика
Статический адаптивный сайт на HTML, CSS и JavaScript. Без сборки и внешних зависимостей.

Откройте index.html или запустите статический HTTP-сервер в этой папке.

## Публикация
Только после подтверждения владельца: создать публичный репозиторий portfolio-site, загрузить main и в Settings → Pages выбрать Deploy from a branch → main → /(root). Все пути относительные. После публикации добавить фактический canonical и og:url.
